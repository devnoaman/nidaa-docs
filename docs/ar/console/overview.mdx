# لوحة نِداء

من لوحة التحكم تجهّز تطبيقاتك وتديرها.

- **التطبيقات والبيئات**: أنشئ تطبيقاً. لكل تطبيق بيئتان منفصلتان `dev` و`prod`.
- **مفاتيح API**: أنشئ مفاتيح SDK (`devices:write`) ومفاتيح خادم (`messages:send`، `messages:read`). المفتاح يظهر مرة واحدة. للتدوير: أنشئ مفتاحاً جديداً، انقل إليه، ثم ألغِ القديم.
- **المزوّدون ← FCM**: ارفع **ملف service-account JSON** من مشروع Firebase **الخاص بك**. راجع [FCM](/providers/fcm).
- **المزوّدون ← APNs**: ارفع مفتاح `.p8` لكل بيئة. راجع [APNs](/providers/apns).
- **كتابة وإرسال**: أرسل إشعاراً من اللوحة. في `prod` يحتاج الإرسال للجميع إلى تأكيد.
- **المواضيع**: أنشئ المواضيع وأدرها. يمكن اختيار الهدف من هذه القائمة.
- **نظرة على الإحصاءات**: أعداد الرسائل والتوصيل (الأهداف، المُرسَلة، الفاشلة، الموصَلة، المفتوحة).

بيانات المزوّد السرية لا تُعاد من أي API ولا تظهر بعد الرفع.
